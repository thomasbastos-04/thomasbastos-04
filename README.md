## 🚀 Projeto principal: Vistor.ia

<p align="center">
  <img src="https://raw.githubusercontent.com/thomasbastos-04/vistor.ia-api/refs/heads/main/docs/assets/logo.png" alt="Vistor.ia" width="240" />

### Visão geral

**Vistor.ia** é uma plataforma SaaS para digitalizar, organizar e acompanhar processos de vistoria com mais eficiência, rastreabilidade e controle operacional.

A solução foi pensada para centralizar:
- modelos de inspeção;
- geração de vistorias;
- compartilhamento de acesso público;
- evidências fotográficas;
- acompanhamento do status e histórico de cada processo.

### Arquitetura

```text
                    Browser
                       │
                     HTTPS
                       ▼
              Angular + Nginx
                       │
                    /api/*
                       │
                Reverse Proxy
                       ▼
                ASP.NET Core 8
                       │
                  EF Core / Npgsql
                       ▼
              PostgreSQL / Supabase
```

### Stack do projeto

- **Backend:** C# · .NET 8 · ASP.NET Core · EF Core · Clean Architecture · DDD
- **Frontend:** Angular · TypeScript · Nginx
- **Banco de dados:** PostgreSQL · Supabase
- **Infraestrutura:** Docker · Railway · GitHub Actions · CI/CD
- **Segurança:** JWT · tokens públicos hashados · HTTPS

### Engenharia aplicada

- Clean Architecture e princípios de DDD
- API REST em ASP.NET Core
- Autenticação e autorização com JWT
- Tokens públicos armazenados por hash
- Frontend e backend em containers independentes
- Nginx como reverse proxy para a API
- PostgreSQL hospedado no Supabase
- Health checks da aplicação e do banco
- CI com GitHub Actions
- Deploy automatizado no Railway

### Roadmap

`Object Storage` → `RabbitMQ` → `Worker` → `Retry/DLQ` → `IA para análise de avarias` → `Observabilidade`

> O Vistor.ia é um projeto pessoal com foco em arquitetura, infraestrutura, produto e engenharia aplicada em um cenário real de negócio.
