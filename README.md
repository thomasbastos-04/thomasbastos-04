**Vistor.ia** é uma plataforma SaaS que estou desenvolvendo para
digitalizar e organizar processos de vistoria.

A plataforma permite criar modelos de inspeção, gerar vistorias,
compartilhar acessos públicos e centralizar evidências fotográficas e o
acompanhamento de cada processo.

### Arquitetura

``` text
                    Browser
                       │
                     HTTPS
                       ▼
              Angular + Nginx
                       │
                    /api/*
                       │
                Reverse Proxy
                       ▼
                ASP.NET Core 8
                       │
                  EF Core / Npgsql
                       ▼
              PostgreSQL / Supabase
```

### Stack do projeto

**Backend:** C# · .NET 8 · ASP.NET Core · EF Core · Clean Architecture ·
DDD\
**Frontend:** Angular · TypeScript · Nginx\
**Database:** PostgreSQL · Supabase\
**Infra:** Docker · Railway · GitHub Actions · CI/CD\
**Security:** JWT · hashed public tokens · HTTPS

### Engenharia aplicada

-   Clean Architecture e princípios de DDD
-   API REST em ASP.NET Core
-   Autenticação e autorização utilizando JWT
-   Tokens públicos armazenados por hash
-   Frontend e backend executados em containers independentes
-   Nginx atuando como reverse proxy para a API
-   PostgreSQL hospedado no Supabase
-   Health checks da aplicação e banco
-   CI com GitHub Actions
-   Deploy automatizado no Railway

### Roadmap

`Object Storage` → `RabbitMQ` → `Worker` → `Retry/DLQ` →
`IA para análise de avarias` → `Observabilidade`

> O Vistor.ia é meu principal projeto pessoal e também um ambiente para
> aplicar arquitetura, infraestrutura e práticas de engenharia de
> software em um produto real.
