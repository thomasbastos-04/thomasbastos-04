## 🚀 Projeto principal: Vistor.ia

<p align="center">
  <img src="https://raw.githubusercontent.com/thomasbastos-04/vistor.ia-api/refs/heads/main/docs/assets/logo.png" alt="Vistor.ia" width="240" />
</p>

**Vistor.ia** é uma plataforma SaaS desenvolvida para digitalizar, organizar e acompanhar processos de vistoria de forma eficiente e escalável.

A solução permite criar modelos de inspeção, gerar vistorias, compartilhar acessos públicos e centralizar evidências fotográficas junto ao acompanhamento de cada processo.

### Arquitetura

```text
                    Browser
                       │
                     HTTPS
                       ▼
              Angular + Nginx
                       │
                    /api/*
                       │
                Reverse Proxy
                       ▼
                ASP.NET Core 8
                       │
                  EF Core / Npgsql
                       ▼
              PostgreSQL / Supabase
```

### Stack do projeto

- **Backend:** C# · .NET 8 · ASP.NET Core · EF Core · Clean Architecture · DDD
- **Frontend:** Angular · TypeScript · Nginx
- **Banco de dados:** PostgreSQL · Supabase
- **Infraestrutura:** Docker · Railway · GitHub Actions · CI/CD
- **Segurança:** JWT · tokens públicos hashados · HTTPS

### Engenharia aplicada

- Clean Architecture e princípios de DDD
- API REST em ASP.NET Core
- Autenticação e autorização com JWT
- Tokens públicos armazenados por hash
- Frontend e backend executados em containers independentes
- Nginx atuando como reverse proxy para a API
- PostgreSQL hospedado no Supabase
- Health checks da aplicação e banco
- CI com GitHub Actions
- Deploy automatizado no Railway

### Roadmap

`Object Storage` → `RabbitMQ` → `Worker` → `Retry/DLQ` → `IA para análise de avarias` → `Observabilidade`

> O Vistor.ia é meu principal projeto pessoal e também um ambiente para aplicar arquitetura, infraestrutura e boas práticas de engenharia de software em um produto real.
